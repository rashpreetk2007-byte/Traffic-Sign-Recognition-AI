# 🚦 Traffic Sign Recognition AI

A mobile-friendly Traffic Sign Recognition project built using Python and Streamlit.

## ✨ Features

- 👤 User Name
- 🚦 Traffic Sign Recognition
- 📤 Image Upload
- 🖼️ Image Preview
- 🎯 Confidence Score
- 🔝 Top-5 Predictions
- 📚 Traffic Sign Library
- 🛡️ Road Safety Assistant
- 📊 Analytics Dashboard
- 🕘 Prediction History
- 📥 CSV Export
- 🧪 Demo Mode
- 🎨 Colourful UI
- 📱 Mobile Friendly

## 🛠️ Technologies

- Python
- Streamlit
- Pillow
- Pandas
- NumPy
- GTSRB Dataset

## 🎯 Purpose

This project demonstrates how artificial intelligence and
machine learning can be used for traffic-sign recognition
and road-safety education.

## ⚠️ Disclaimer

This is an educational project and should not be used as
a replacement for official traffic signs, traffic signals,
or professional driver-assistance systems.
